# Ashen Maleesha Edward — Portfolio

A lightweight, responsive portfolio for Ashen Maleesha Edward, built with plain HTML, CSS, and JavaScript. No build step or backend is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Deploy with GitHub Pages

1. Push these files to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The portfolio is prefilled with information from Ashen's CV and public GitHub repositories. Review the content and links in `index.html` before publishing. The profile photo loads from the public GitHub avatar, and the contact email and LinkedIn link are from the CV. Phone number and street address are intentionally not published.
